# Java Annotations and Reflection

A Java project demonstrating the use of **custom annotations** and the **Reflection API**.

## Task

Create a custom annotation with an integer parameter and a class containing public, protected, and private methods with parameters.

Some of the methods are annotated with the custom annotation.

Another class uses Reflection to find the annotated protected and private methods and invoke each of them the number of times specified by the annotation parameter.

The calling code does not depend on the number or types of parameters of the invoked methods.

## Main Concepts

The project demonstrates:

* custom annotations;
* annotation parameters;
* Java Reflection API;
* accessing protected and private methods;
* invoking methods dynamically;
* working with methods regardless of their parameter count and types.

## Technologies

* Java
* Custom annotations
* Reflection API
* Object-oriented programming

## Demonstration

The program demonstrates how annotated methods are discovered and invoked dynamically according to the value specified in the annotation.
